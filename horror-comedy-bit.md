## 1. The Thesis (the spine of the whole thing)

**Two sides of the same coin: horror and comedy.** Both work by setting up
tension and then snapping it. Horror holds the tension; comedy releases it.
Same machine, opposite exit doors.

- **Core premise:** *Laughter casts out evil.* A genuine laugh is involuntary —
  you can't fake it and you can't be afraid in the same instant. So the comic is,
  functionally, an exorcist with a two-drink minimum.
- **The hecklers-as-proof bit:** if laughter really casts out the dark, then the
  heckler is the true test — the one demon in the room actively resisting the
  cleansing. A great comic doesn't fight the heckler; they *exorcise* them by
  getting the whole room to laugh at the same time. The room becomes the holy water.
- **Tone target:** sincere underneath the jokes. The audience should half-believe
  the thesis by the end — that's what makes the laugh land *and* linger.

## 2. Act / Set Structure (rough)

1. **Cold open** — a haunted-mansion story told straight, building real dread...
   then the lights-on punchline. Establishes the horror→comedy snap.
2. **The thesis** — "laughter casts out evil" delivered as a half-serious sermon.
3. **The doctor / RX runner** — the recurring character thread (see §4).
4. **Heckler theology** — hecklers as the test, the room as the exorcism.
5. **Closer** — circle back to the cold-open mansion; the ghost gets the last laugh.

## 3. Bits — Haunted Mansions

The opener engine. Tell each one *straight* first, then twist.

- **The Mansion Tour** — every "do NOT enter that room" tour, except the scary
  room is just where they keep the HOA paperwork.
- **Shadow people** — what the shadows are actually doing when no one's filming
  (mundane, domestic, bored ghosts).
- **The reaper documentation bit** — treat death/the reaper like a contractor who
  shows up, takes measurements, and leaves a quote you have to think about.
  > Runner phrase to keep: *"true reaper documentation."* Lean into the
  > bureaucracy-of-the-afterlife angle.

---

## 4. Recurring Thread — The "Doctor" / RX / Occult-Science Runner

A character/voice: the quack "doctor" of occult science handing out prescriptions.

- **"The doctor ordered..."** — every diagnosis ends with the same Rx.
- **"Prototype RX"** — the in-world pharmacy/brand. Tagline candidates:
  - *"Prototype RX — side effects may include an encore."*
  - *"Metal is the medicine the doctor ordered."* ← strong closer line
- **Metal-as-medicine** — the joke that the only prescription that actually casts
  out the demons is turning the amp up. Ties the §1 thesis (laughter exorcises)
  to a second cure (volume exorcises). Two medicines, same coin.
- Keep it absurd but internally consistent — the "occult science" should have its
  own dumb rules it always obeys. That consistency is where the laughs compound.

> **Combine-or-separate note:** the Doctor/RX thread can live as its own short set
> OR thread through the horror set as the "explanation" for everything. Decide per
> venue — flagging it here so the choice stays intentional.

## 5. Production / Recording Plan

The "record it, learn from it" side. Practical, so the bits actually get captured.

- [ ] **Capture everything** — set runs to video + isolated audio (sound bites are
      gold for short-form clips later).
- [ ] **Two-mic minimum** — one on the comic, one on the room (you need the
      *laughter* on tape; it's the proof of the thesis and the best clip fuel).
- [ ] **Broader frequency spectrum** — capture wide (low rumble for the horror
      cold-opens, full range for the room). Don't gate the low end out.
- [ ] **Shadows project** — visual/lighting bit for the haunted segments
      (silhouettes, shadow-people gags). Storyboard separately.
- [ ] **Review loop** — after each set, log: what landed, what died, what the
      heckler did. The heckler data is the most useful (see §1).
- [ ] **Clip pipeline** — mark timestamps live so the best 30–60s pull straight
      to short-form.
